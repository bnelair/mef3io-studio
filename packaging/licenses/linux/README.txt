Licence texts for Linux system libraries whose packages (on the AlmaLinux 9
build machine) install no licence file at all. collect_licenses.py uses these
only when the package itself, its documentation and its sibling packages
carry nothing. Fetched from the upstream projects:
  libxcb             https://gitlab.freedesktop.org/xorg/lib/libxcb (COPYING, MIT)
  xcb-util-keysyms   https://gitlab.freedesktop.org/xorg/lib/libxcb-keysyms (COPYING, MIT)
