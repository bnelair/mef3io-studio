# Not released yet

- **Overview of the whole recording in the signal viewer.** A band above the
  coloured timeline bar shows the lowest and highest value of a channel over
  the whole recording, so you can see where to go before the slow loading of
  a page. The frame of the current page reaches up over the band, and clicking
  or dragging on it moves there. The **Overview** button chooses the channels
  (the first shown by default, up to four, each scaled to its own size);
  channels you hide leave the band. It is read in the background from the
  recording that is already open, never loading the signals.
