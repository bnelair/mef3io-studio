This is **0.1.3** (not released yet), after
[0.1.2](https://github.com/bnelair/mef3io-studio/releases/tag/v0.1.2).

## Fixed

- **The signal viewer no longer leaves a page empty after a brief read
  error.** If part of a recording could not be read for a moment (for
  example a network or USB drive that dropped out and came back), the next
  page could stay empty until you moved again. It is now read again.
