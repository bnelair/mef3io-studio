This is **0.1.5**: not released yet.

## Fixed

- **"Checking everything before starting" in Join or trim is much quicker on
  big recordings.** It used to open every recording again and walk through all
  of its folders, which took tens of thousands of file requests (minutes on a
  network drive). It now uses what Explore already knows about each recording
  (when it starts and ends, its channels and its size) and touches each
  recording folder once, only to see that it has not changed since Explore
  read it. If it has changed, the recordings are checked afresh. The check
  that Join or trim's library does before it writes is unchanged.
- **Sending a range from the signal viewer to Join or trim now keeps your
  channel choice.** Join or trim stops at the **Channels** step, with the
  channels you could see in the viewer kept and the ones you hid left out, so
  you can see and change which channels go into the new recording.

## Changed

- **Choosing a few channels is easier to find.** The channel step now says
  that a ticked box means "kept" and explains how to keep only a few: choose
  **Exclude all**, then tick the channels you want.
